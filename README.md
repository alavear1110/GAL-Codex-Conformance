# GAL · Codex Validation

Supporting validation repository for **GAL Labs / GAL Method — Guide · Align · Lead**.

This is an isolated runtime-only GAL v0.5.0 baseline. The [root loader](AGENTS.md) points to GAL Core and the canonical Codex adapter. See the [runtime README](runtime/README.md) for state, generated-view, and execution rules.

Keep blind-test scenarios, expected answers, grading criteria, transcripts, and prior results outside this environment. Repository-context documents orient contributors; they do not alter GAL Core, upgrade this baseline, or establish new host compatibility.
